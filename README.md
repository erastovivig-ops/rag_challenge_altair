# RAG Challenge от Альтаира

## Какую задачу вы решали?

**Задача** заключалась в сборке RAG-системы: 

* получить вопрос,
* найти подходящие chunks,
* собрать context,
* передать его языковой модели,
* вернуть ответ по источникам.

## Какую часть работы выполняли самостоятельно?

**Самостоятельно** было выполнено доведение бейзлайна до прототипа ML-модели: написание кода функций семантического поиска, построения контекста, ответа, threshold, chunks и embeddings, написание промпта, подбор вопросов, тесты, формирование базы знаний.

## Какой результат получили?

**Результатом** стала простая модель, специализирующаяся на ответах по теме computer science. Она кратко отвечает на вопрос пользователя, используя данные из базы знаний, указывает источники и имеет базовую защиту от галлюцинаций: умеет говорить "я не знаю" при отсутствии явного ответа в источниках.

## Что можно было бы улучшить при дальнейшем развитии проекта?

**Первое, что я бы улучшил:** дополнил базу знаний. Сейчас это всего 3 файла, из за чего ML модель часто не сможет ответить на вопрос.

**Второе:** добавил бы семантический чанкинг, чтобы чанки разбивались по смысловым блокам.

**Третье:** векторная БД для масштабирования в серьезный проект.
